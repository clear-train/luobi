# 词语收敛游戏 · 三家对跑记录

**规则**：每位玩家一个厂家模型，每轮同时各说一个词；所有人看得到此前每一轮所有人的词（全透明，无信息不对称）；判定标准统一为**字面完全相同**（去标点空白后逐字比对）。全体在同一轮说出同一词即结束。

**入场席位**（每厂只取最省的一档，均来自当前网关实际可用的模型；探了 12 个模型 id，只有这 3 个可用）

| 席位 | 厂家 | 模型 |
|---|---|---|
| P1 | DeepSeek | deepseek-v4.1-flash |
| P2 | 智谱 | glm-5.3-flash |
| P3 | 小米 | mimo-v2.6-flash |

> 作废：早前用 OpenAI gpt-6-astra 跑的两局不算数——那是该家最贵的一档，选型错了，已整段撤掉，工作区里的 codex 适配脚本和登录态副本也一并删除。
> 未入场：opencode zen 免费额度用尽；Claude CLI 未登录；gpt / claude / kimi / qwen / nemotron 等 id 在本网关均不可用。

## 局 A（无约束）

| 轮 | DeepSeek | 智谱 | 小米 |
|---|---|---|---|
| 1 | 苹果 | 苹果 | 太阳 |
| 2 | **苹果** | **苹果** | **苹果** |

收敛轮次：**2**，收敛词「苹果」。

## 局 B（约束：只许两字抽象名词，禁止具体物体/自然物/颜色等）

| 轮 | DeepSeek | 智谱 | 小米 |
|---|---|---|---|
| 1 | 快乐 | 希望 | 幸福 |
| 2 | 幸福 | 幸福 | 快乐 |
| 3 | 幸福 | 快乐 | 幸福 |
| 4 | 幸福 | 快乐 | 幸福 |
| 5 | **幸福** | **幸福** | **幸福** |

收敛轮次：**5**，收敛词「幸福」。

## 观察

1. **无约束时几乎看厂家**：第 1 轮只要有一家撞上多数，第 2 轮就收工；两家说「苹果」、小米一家的「太阳」直接归顺。信息全透明时收敛快得毫无信息量。
2. **加约束才有戏**：局 B 第 1 轮三家三个词（快乐/希望/幸福），没有多数，靠"猜对方会往哪边靠"来推，花了 5 轮。
3. **最抢眼的是第 3~4 轮的僵局**：DeepSeek 和小米都锁死在「幸福」，智谱单独死守「快乐」，连续两轮 2:1 谁也不动——不是因为看不见，而是多数派觉得该少数派让、少数派觉得该多数派让。第 5 轮智谱才松口。
4. 所以真正能测出厂家差异的不是"几轮收敛"，而是**第 1 轮的先验词**和**僵局里谁先让步**。DeepSeek/小米 两轮不动，智谱先崩。
5. 想要更狠的区分度，改判定而不是改词：语义相同即赢（上裁判）、禁高频词、或每轮只能由全体接受一个新词（真谈判）。

## 复跑

所有对局通过 DSH 的 `agent(prompt, { model })` 调用，一个 workflow 脚本 = 一轮，把上一轮的表塞进 `history` 即可：

```js
const seats = [
  { p: "P1", vendor: "DeepSeek", model: "deepseek-v4.1-flash" },
  { p: "P2", vendor: "智谱",     model: "glm-5.3-flash" },
  { p: "P3", vendor: "小米",     model: "mimo-v2.6-flash" }
];
const out = await parallel(seats.map(s => () => agent(build(s.p, history, rnd), { label: s.p, model: s.model })));
```

判定：`new Set(三个词).size === 1`。
