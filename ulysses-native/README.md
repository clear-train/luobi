# Ulysses Native

一个安静的长文写作工具：左边是文稿列表，中间是一张纸，Markdown 边写边排版。原生 AppKit、单窗口，所有文字都存在本机的一个 JSON 文件里。

## 启动

双击 `build/UlyssesNative.app`；也可以在本目录的终端里执行：

```bash
open build/UlyssesNative.app
```

第一次启动会自动建一篇「第一章」，光标停在正文末尾，直接写就行。

## 功能

- **多文稿侧栏**：点击切换；顶部搜索框实时过滤标题与正文；`+` 新建一篇。
- **大标题**：编辑区顶部直接改标题，改完即存。
- **打字机模式**：光标行始终停在窗口垂直中间，视线不用上下追（视图菜单可开关，⌥⌘T）。
- **Markdown 实时排版**：`# ` 到 `###### ` 六级标题、`**加粗**`、`> 引用斜体灰`；标记符号保留在正文里，导出仍是 Markdown。
- **字数统计**：中文按字、英文按词，状态栏显示「约 N 字」。
- **写作目标**：视图菜单「设定写作目标字数…」，底部出现细进度条，达标变绿。
- **两套主题**：羊皮纸 / 深夜，视图菜单「切换主题」（⌥⌘Y）。
- **自动保存**：停止输入 0.8 秒写入磁盘；菜单「立即保存」（⌘S）。
- **文件菜单**：新建（⌘N）、导入 Markdown（⌘O，可多选）、导出本篇（⌘E）、导出全部、删除本篇（两步确认）。
- **使用指南**：帮助菜单「使用指南」（⌘/），快捷键速查和常见问题都在里面。
- **顶部工具栏**：新建 / 导入 / 导出 / 打字机 / 排版 / 主题 / 目标 / 指南 做成一排小按钮，不想记菜单就点它们。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| ⌘N | 新建文稿 |
| ⌘S | 立即保存 |
| ⌘O | 导入 Markdown（可多选） |
| ⌘E | 导出当前文稿 |
| ⌥⌘M | Markdown 排版开关 |
| ⌥⌘T | 打字机居中开关 |
| ⌥⌘Y | 切换主题（羊皮纸 / 深夜） |
| ⌥⌘G | 设定写作目标字数 |
| ⌘/ | 打开使用指南 |

编辑动作沿用 macOS 习惯：⌘Z 撤销、⇧⌘Z 重做，⌘C / ⌘V / ⌘X / ⌘A 照常。

## 文件在哪里

| 内容 | 路径 |
| --- | --- |
| 全部文稿与设置 | `~/Library/Application Support/UlyssesNative/state.json` |
| 导出的 Markdown | `~/Documents/UlyssesNative/` |

`state.json` 里装着所有文稿（标题、正文）、当前选中篇、主题、写作目标和各开关状态。在 Finder 里按 ⇧⌘G 粘贴上面的路径（`~` 会展开成你的用户目录）就能直接跳过去。

## 备份

- **最省事**：拷贝 `state.json`。拷走这一个文件就拷走了全部文稿，换电脑时放回同一路径即可。
- **可读的备份**：定期 ⌘E 导出本篇；「文件 → 导出全部文稿…」会把所有文稿合成一个 Markdown 文件。
- 导出不会覆盖同名文件，重名会自动变成 `-2`、`-3`，所以放心多导几次。

## 常见问题

**中文输入法会吞字吗？**
不会，组字过程中的内容照常进入正文。如果输入时觉得 Markdown 排版有点跳，⌥⌘M 先关掉排版，写完这一段再打开。

**字数怎么算？**
中文（含日文假名）按字，英文和数字按词，标点和空格不计；只算正文，不算标题——所以状态栏写「约」。

**主题重启后记不住？**
主题存在 `state.json` 里，切换时会立刻保存。如果重启又回到羊皮纸，先看状态栏有没有「保存失败」，再确认 `state.json` 没被删除、磁盘没满。

**底部进度条怎么不显示？**
写作目标为 0 时它是隐藏的。用 ⌥⌘G 设一个大于 0 的字数就会出现。

**删掉的文稿能找回吗？**
删除是两步确认、不可撤销。请靠备份找回：之前拷过的 `state.json`，或导出过的 Markdown。

## 重新编译

不需要 Xcode，用 `swiftc` 命令行编译：

```bash
./build.sh
```

看到「构建完成」即成功，产物仍是 `build/UlyssesNative.app`。
