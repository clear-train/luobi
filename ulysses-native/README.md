# Ulysses Native

一个本地、安静、只属于你自己的写作工具：分组和文稿都保存在你电脑上的一个 JSON 文件里，不联网、不弹窗、不催你。原生 AppKit 写的单窗口应用，用 Markdown 边写边排版。

## 第一次打开

双击 `build/UlyssesNative.app`，或在本目录的终端里执行：

```bash
open build/UlyssesNative.app
```

第一次启动会自动建一篇「第一章」。你会看到三块东西：

- **左边**是一棵文稿树，一开始只有「第一章」这一篇。
- **中间**是一张纸，标题在上面、正文在下面，光标已经停在正文末尾。
- **右上角**是分组排开的按钮：＋ 新建文稿、▤ 新建分组 ｜ 导入、导出 ｜ 收起侧栏、打字机、排版 ｜ 外观、指南。鼠标停上去会显示每个按钮做什么。

先做一件事就够了：在纸上写下第一句话。别的都可以以后再说。

第一次打开会自动弹一次使用指南；以后想再看，点右上角「指南」、侧栏最下沿的「功能说明」，或菜单「帮助 → 功能说明与使用指南」。

## 界面导览

| 位置 | 作用 |
| --- | --- |
| 左侧栏 | 文稿树。分组可以嵌套，点文稿切换，右键管理文稿与分组；点顶部「收起侧栏」可折叠 |
| 中间纸张 | 你的正文。标题在编辑区顶部，可直接改；Markdown 实时排版 |
| 底部状态栏 | 显示篇数、「约 N 字」和当前的保存状态 |
| 顶部按钮排 | ＋ 新建文稿、▤ 新建分组、导入、导出、收起侧栏、打字机、排版、外观、指南，全部可点、都有悬浮说明 |

## 文稿与分组

### 新建文稿

点顶部「＋ 新建文稿」，或按 ⌘N。新文稿落在当前选中的分组里。

### 新建分组

点顶部「▤ 新建分组」，或右键侧栏空白处选「新建分组」。分组就是文件夹，可以一层层嵌套，比如「小说 → 第一卷 → 第 01 章」。

### 拖动归档

按住一篇文稿，拖到目标分组上松手即可；也可以把一个分组拖进另一个分组，做出嵌套。拖错了再拖回来就好。

### 重命名

右键文稿或分组，选「重命名」，原地输入，回车确认。

### 删除

右键 →「删除」是**两步确认**：先删，再确认一次。删除不可撤销，请先备份（见下面的「数据与备份」）。

## 外观

点顶部「外观」打开面板：

| 配色 | 适合 |
| --- | --- |
| 羊皮纸 | 白天，纸感最重 |
| 米白 | 白天，最干净 |
| 护眼绿 | 长时间盯着屏幕 |
| 深夜 | 夜里写 |

正文字号 15–20pt，拖动滑块即时生效。选完会自动保存，不用点确定，下次打开还是这一套。

## 导出成书

写完一章不代表能交出去。点顶栏「成书」（或文件菜单 → 导出整本书…）会把稿子按**侧栏顺序**拼成一整本：

- **网页 .html**：双击用浏览器打开就能读，按 ⌘P 直接打印；排版是宋体、首行缩进、约 40em 的阅读宽度。
- **Markdown .md**：保留原来的标记，方便你继续用别的工具改。

可选「全部文稿」或「当前分组及其子分组」——写小说时把「素材」「人物小传」这类分组排除在外，只导出正文章节。

顺序规则：同一层先走分组、再放没归组的零散文稿；分组的名字变成一个标题。所以**侧栏里怎么排，成书就怎么排**。

文件落在 `~/Documents/UlyssesNative/`，导出完会自动在访达里选中它。

## 调整顺序

侧栏里的顺序就是成书时的顺序，所以它值得能调。

- **拖动**：按住一篇文稿上下拖。拖到某篇的上方就插在它前面，拖到分组名上就归到该组末尾，拖到空白处就回到最外层。
- **右键**：「上移一位 / 下移一位」。只在同一分组内移动，不会意外跨组。
- 顺序保存在 `state.json` 里，重开照旧；「成书」导出的章节顺序完全跟随侧栏。

## 搜索

左上角的搜索框搜的是**标题 + 正文**，不是只搜标题。

- 输入关键词，侧栏变成扁平的结果列表：每行是「标题 + 命中片段」，命中词会标出来，一眼能看出为什么这篇被搜到。
- 点一条结果，除了切换文稿，还会把光标带到命中的位置，并让它落在屏幕中间。
- 标题命中的文稿不跳正文，只切过去（因为标题本身就是你要找的）。
- 状态栏会写「搜索「枣树」：2 篇命中，点一条跳到命中处」；没有命中会直接告诉你。
- 点搜索框右边的 ⊗ 清空，侧栏恢复成正常的文稿树。

## 写作目标

写作最难的是「今天有没有推进」，所以目标按**天**算，不按全书总量。

- 侧栏左下角点「写作目标」（或视图菜单 → 今日写作目标…），填每天多少字，`0` = 不设。
- 底部细进度条实时显示今天写了多少；达标变绿。
- 状态栏右侧常驻「今日 156/500」，不用打开任何面板。
- 面板里还能看到**连续达标天数**。

计数方式很朴素：App 记住「今天开工时全书多少字」，之后用当前总数去减。好处是不用监听每一次敲键，删改也不会算错方向——你今天删掉的字，会从今日进度里扣回去。

## 写作手感

| 按钮 | 做什么 | 适合什么时候 |
| --- | --- | --- |
| 缩进 | 每段首行空两格（默认开） | 写中文长篇，版面更像书 |
| 打字机 | 光标所在行固定在屏幕中间 | 长时间写，眼睛不追着跑 |
| 专注 | 收起侧栏与工具栏，正文收成居中一栏 | 不想被任何东西打扰时 |

- 专注模式下按 **Esc**（或点右上角「退出专注」）回到完整界面。
- 底部状态栏是「篇数 · 本篇字数 · 全书字数」，写长篇时能看到总量在涨。

| 快捷键 | 作用 |
| --- | --- |

编辑动作沿用 macOS 习惯：⌘Z 撤销、⇧⌘Z 重做，⌘C / ⌘V / ⌘X / ⌘A 照常。

## 数据与备份

整个文稿库——分组、文稿、偏好——就是一个 JSON 文件：

| 内容 | 路径 |
| --- | --- |
| 全部文稿与设置 | `~/Library/Application Support/UlyssesNative/state.json` |
| 上一版（自动） | `~/Library/Application Support/UlyssesNative/state.json.bak` |
| 定时快照（自动，留最近 20 份） | `~/Library/Application Support/UlyssesNative/Backups/` |
| 导出的 Markdown | `~/Documents/UlyssesNative/` |

App 内置了三层保险，日常不需要你操心：

1. **每次保存前**把上一版留成 `state.json.bak`（一步后悔药）；
2. **每 5 分钟**存一份带时间戳的快照到 `Backups/`，最多 20 份（慢慢后悔药）；
3. **主文件读不出来时**自动按「主文件 → `.bak` → 最新快照」的顺序恢复，状态栏会写明发生了什么。

手动控制都在**文件菜单**里：`立即备份一份`（马上存快照，写长稿前点一下很安心）、`从备份恢复…`（挑一份快照换回来，当前内容会先自动存一份快照，所以恢复错了也不会丢）、`打开备份文件夹`。

- **复制即备份**：把 `state.json` 拷到 U 盘或网盘，就是一次完整备份。
- **换机带走**：在新电脑上放回同一路径，打开就是原来的文库。
- **建议定期备份**：比如每周拷一次，文件名带上日期，找回时好认。
- Finder 里按 ⇧⌘G 粘贴上面的路径（`~` 会展开成你的用户目录）就能直接跳过去。

## 常见问题

**写着写着字丢了怎么办？**
先别慌，去 `state.json` 看一眼；如果同时在别处打开过，也可能被旧文件覆盖。所以定期备份这一个文件最省心。

**能不能导出？**
能。⌘E 导出当前文稿；菜单「文件 → 导出全部文稿…」会把所有文稿合成一个 `.md`。导出是追加式命名，同名文件不会被覆盖。

**支持多窗口吗？**
不支持，这是单窗口设计：一张纸，一次写一篇。

**怎么彻底清空？**
退出 App，删掉 `state.json`，再打开就是全新的空文库。

**没有网络能用吗？**
能，它本来就不联网。

## 写在后面

这是为「记录自己」做的小工具：不追功能，不卷同步，不打扰你。别被上面这些功能绑架——分组可以不建，主题可以不换，快捷键可以不用。先写起来，工具的事情交给工具。

## 打包与发布

仓库里带了打包脚本，一条命令出安装包：

```bash
./tools/release.sh            # 只在本地打包
./tools/release.sh --publish  # 打包并顺手发一个 GitHub Release
```

产物在 `dist/`：

| 文件 | 用途 |
| --- | --- |
| `UlyssesNative-<版本>-macOS.zip` | 解压后把 App 拖进「应用程序」即可，发给别人也用这个 |
| `UlyssesNative-<版本>.dmg` | 双击挂载、拖进 Applications（部分受限环境做不了 dmg，会自动跳过） |

版本号只有一个真相：`Info.plist` 里的 `CFBundleShortVersionString` / `CFBundleVersion`，发版前改这里。

安装到别人机器上时：
1. 解压 zip，把 `UlyssesNative.app` 拖进「应用程序」；
2. 第一次打开要**右键 → 打开**（没做 Apple 公证，双击会被 Gatekeeper 拦一次）；
   或在终端执行 `xattr -dr com.apple.quarantine "/Applications/UlyssesNative.app"`；
3. 文稿库仍在 `~/Library/Application Support/UlyssesNative/state.json`，换机拷这个文件就行。

> 从终端或别的受限环境里启动 App 时，系统可能禁止它写 Application Support，状态栏会提示「保存失败」。正常从访达双击启动没有这个问题。
