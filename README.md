# 写作工具：Ulysses Native

这个仓库里和"写作"有关的只有一个东西：**`ulysses-native/`**，产品名 **Ulysses Native**（macOS 原生写作应用）。

- 应用说明、快捷键、数据位置 → [`ulysses-native/README.md`](ulysses-native/README.md)
- 安装包 → [Releases](https://github.com/clear-train/ulysses-native/releases)
- `legacy/` 里是最早的 HTML 原型和一次失败的套壳尝试，**不维护**

以前它还叫过 `ulysses-lite` / `ulysses-app`，那些名字都指这一件事，现在统一叫 Ulysses Native。

（`codex_poke/`、`word-game/` 是与写作工具无关的其他项目，恰好放在同一个目录里。）
